Drop screenshots into the folder named after each project (dialer, symphony, lea-ai, ...).
Then list them in data.js, e.g. on a project:

  shots: ['assets/projects/lea-ai/chat.jpg', 'assets/projects/lea-ai/dashboard.jpg'],
  links: [{ label: 'Live demo', url: 'https://...' }, { label: 'Repository', url: 'https://github.com/...' }]

Tip: ~1600px wide JPG/WebP, and blur anything confidential (client data, internal screens).
